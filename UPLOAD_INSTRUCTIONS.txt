# Upload to GitHub

1. Open the repository:
   Marcobedendo78/Waveshare-ESPHome-Home-Assistant-Dashboard
2. Use **Add file → Upload files**.
3. Drag the CONTENTS of this folder into the GitHub upload area, preserving folders.
4. Commit message:
   `Prepare v1.0.0 initial public release`
5. Commit directly to `main`.

After upload, verify that README.md renders images correctly and that the repository contains:
- esphome/
- home-assistant/
- docs/images/
- README.md
- CHANGELOG.md
